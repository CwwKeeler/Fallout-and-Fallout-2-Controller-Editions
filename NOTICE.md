# Modification notice

This repository contains modified copies of Alex Batalov's Fallout Community
Edition and Fallout 2 Community Edition. The changes add native controller
input, direct analogue movement, camera panning and follow behavior, a custom
controller interface and on-screen keyboard, borderless fullscreen support,
renderer recovery, automated controller tests, Windows compiler fixes, and a
Fallout 1 enemy-target initialization fix.

No proprietary Fallout game assets or original game executables are included.
Users must supply assets from a legally obtained copy of each game.

The original projects are available at:

- https://github.com/alexbatalov/fallout1-ce
- https://github.com/alexbatalov/fallout2-ce
