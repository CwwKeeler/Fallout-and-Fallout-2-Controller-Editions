# Fallout 1 & 2 Controller Editions v1.0.0

This is the first packaged Windows release of the Controller Editions.

## Download the right file

- **Fallout 1:** `fallout1-ce-controller-windows-x64.zip`
- **Fallout 2:** `fallout2-ce-controller-windows-x64.zip`

Install instructions for beginners are included in each download and available
in the [Easy Windows installation guide](https://github.com/CwwKeeler/Fallout-and-Fallout-2-Controller-Editions/blob/v1.0.0/INSTALL-WINDOWS.md).
`RELEASE-SHA256SUMS.txt` contains checksums for both downloads.

## Highlights

- Native support for controllers recognized by SDL, with a large bundled mapping
  database for Xbox, PlayStation, Nintendo, 8BitDo, and generic devices.
- Direct left-stick movement with walking, running, collision, and combat AP.
- L3 switching between direct movement and point-and-click controls.
- Smooth right-stick camera panning and gradual character following.
- Fallout-style controller interface, remapping, actions, settings, help, and an
  on-screen keyboard.
- Borderless fullscreen with Alt+Enter and safe Alt-Tab behavior.
- The movement hex hides during direct analogue control while interaction and
  targeting cursors remain available.
- Fallout 1 enemy-turn crash fix.

These downloads contain replacement engines and support files only. You must
own and install the original games separately. No commercial Fallout assets are
included.
