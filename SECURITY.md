# Security policy

Please report security issues privately through GitHub's **Report a
vulnerability** feature when it is enabled for this repository. Do not include
original Fallout game data, save files, account credentials, or other personal
information in an issue or reproduction archive.

Controller compatibility problems and ordinary crashes can be filed as public
issues with steps to reproduce, controller model, connection type, operating
system, and relevant engine logs. Remove local filesystem paths and personal
information before attaching logs.
